# Stack implementado
- Java 21 como versión de compilación, compatible con JDK 24.
- Spring Boot 3.5.7, MVC y Bean Validation.
- Spring Security: CSRF, cabeceras y BCrypt.
- Hibernate / Spring Data JPA y H2 en archivo.
- Spring Mail para SMTP.
- HTML, CSS y JavaScript sin compilación adicional.
- Maven, JUnit 5, Spring Boot Test y Mockito.

Spring Boot se eligió para reutilizar el entorno Maven existente.
